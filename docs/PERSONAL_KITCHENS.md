# 个人厨房与可选家庭

登录后直接进入个人厨房，默认一人用餐。食材、菜单、采购、记录和社区都可以独立使用，无需创建家庭。

个人中心 → **家庭共享**：需要协作时展开“创建或加入家庭”，新建共享厨房或输入与当前账号邮箱匹配的邀请。已有家庭也在这里选择。家庭模式的个人中心提供“使用个人厨房”。

个人与家庭的食材、菜单、采购和记录分别保存，切换不复制、搬移或合并数据。既有家庭及权限保留。个人厨房禁止邀请和加入其他成员，家庭管理员无权访问他人的个人厨房。社区动态公开分享需单独确认，收藏和积分属于账号。

新登录默认进入个人厨房；明确选择的空间在刷新后保留。升级时旧家庭默认选择只忽略一次，已有家庭数据仍可从个人中心找到。厨房偏好可调整默认人数与忌口，单餐和连续餐次规划继承当前厨房人数。

底层继续使用 kitchen/household ID 保持事务隔离。`PUT /me/personal-kitchen` 只按会话用户在账号锁内幂等创建。迁移 034 不转换既有家庭；降级拒绝把已存在的个人厨房静默改成共享家庭。

互补账号合并仍要求双方密码、短信证明和明确确认。目标已有个人厨房时保留其默认，否则接管来源默认；两边厨房及历史分别保留且仅合并后的账号可用，额外个人厨房可从个人中心选择。

营养记录是已记录餐次的食材估算，不等同于实际个人摄入，也不自动测量家庭分餐。AI 额度按当前厨房及服务总额限制，切换空间不能绕过服务上限。

# 语音添加食材

实验状态：2026-10-15 完成 [100 次文本语义理解对照](INTAKE_SEMANTIC_EVAL.md)。模型完全符合 75/100，但仍产生七条不合格草稿，暂未接入正式录入。现有 ASR＋保守规则、显式确认流程保持不变。

在“食材库存 → 添加与补充食材”使用“说一说，添加食材”。先同意本次录音发送至百炼，再开始录音或上传 WAV、WebM、Ogg、MP3，点击“识别这段录音”。浏览器录音最长 60 秒，上传最大 5 MiB。麦克风需要 HTTPS 或 localhost 安全上下文及浏览器授权；不支持录音的浏览器可上传文件或使用目录。

说出食材、数量和单位，例如“西红柿半斤，鸡蛋六个”。结果会显示转写原文和可编辑草稿。请对照原文检查遗漏，选择正确目录食材、补齐数量，可以移除或增加条目、补充位置和日期，最后勾选核对并确认入库。数量按目录默认单位展示；名称别名、公斤/斤/两与克、升与毫升支持精确换算。包装和重量、重量和个数不能自动换算；缺少数量、否定、修改和不明确内容要求核对。不推断保质期、包装容量、未知食材或权威余量。

这是有界语音入库助手：Qwen ASR 负责转写，本地确定性解析器整理常见名称/数量表达，不是任意自然语言的多轮 Agent。一次任务最多 20 项草稿，复杂口语、方言、噪声、同名歧义和漏识别仍需用户纠正。识别完成不增加库存；确认时整份草稿的批次、不可变流水、Outbox 和任务终态共享事务。

已覆盖“别加、取消、去掉、撤回、不对、改成、改为”等明确否定/改口表达。遇到这些词或估计词时整段所有草稿数量留空，包括标点前的数量，要求用户移除无效条目、填写后确认。系统不猜指代或取最后数量；保守规则可能清空无关条目，有限词表不能覆盖所有自然语言否定。

2026-10-15 已完成 [九段语音与一张图片的真实 OSS 任务链路](OSS_MODEL_CHAIN.md)；正常音频删除通过，中断恢复仍未验收。

## 百炼配置

北京地域新业务建议复制控制台当前业务空间的 Base URL，将下面 `<WorkspaceId>` 替换为业务空间 ID。旧 DashScope 域名仍可用，但已进入维护状态。[官方接入说明](https://help.aliyun.com/zh/model-studio/get-api-key/)

在本地未提交的 `.env` 设置独立配置，API 与 Worker 都需要相同语音配置。不会继承文字/视觉模型的密钥。

```dotenv
SPEECH_MODEL_ENDPOINT=https://<WorkspaceId>.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
SPEECH_MODEL_NAME=qwen3-asr-flash
SPEECH_MODEL_API_KEY=<你自己的北京地域百炼密钥>
AI_ALLOWANCE_ENABLED=true
AI_SPEECH_CALL_ALLOWANCE_CNY=0.10
```

地址和密钥必须属于同一地域。其他地域请依据百炼控制台和 [Qwen 录音识别文档](https://help.aliyun.com/zh/model-studio/recording-file-recognition-qwen) 设置兼容接口地址。实现发送 Base64 音频，不公开音频 URL。上面的 0.10 元是每次应用预扣示例，不是服务商价格或实际账单封顶；启用前核对自己的模型价格和月度、每日、并发额度。更改配置后重新创建 API 与 Worker 容器。

上传使用稳定幂等键，断线重放不会生成第二个收费任务。Worker 每个语音任务只发送一次；失败或结果不确定不自动重发，也不允许原任务重新派发。需要再次识别时重新录音并明确提交新任务，既有预扣不会因此退款。识别后、失败处理或取消时尝试删除暂存录音；排队期间录音在共享对象存储中，不提供音频下载接口。主机中断、过期租约或对象删除失败可能留下暂存对象，管理员应按任务状态核查后清理，不能删正在排队/运行的录音或业务图片。转写和草稿作为私有厨房任务记录保留。

## 验证范围

默认验证使用本地 HTTP 转写 fixture，不调用百炼。API 集成检查权限、同意、音频格式、幂等上传、单次预扣、取消/租约 fencing、整份入库回滚和重放。浏览器验收使用合成录音与模拟麦克风，验证草稿编辑、补齐未知数量、确认和无横向溢出。它们不证明真实麦克风设备、真实百炼连接、方言或噪声准确率；真实收费模型测试需另行明确授权。

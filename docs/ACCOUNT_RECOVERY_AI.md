# 学习阶段账号找回与 AI 额度

## 账号恢复码

登录后打开个人主页，在“账号恢复码”输入当前密码并明确确认，生成五个随机 128-bit 恢复码，180 天有效。新一组码会替换旧码，只在当前页面显示一次；数据库仅保存 SHA256 和账号凭证版本。请保存在可信的密码管理器或纸上，确认保存后隐藏。页面、日志和数据库不提供重新查看明文的接口。

忘记密码时，在登录页选择“忘记密码 → 使用恢复码”，提供原邮箱或手机号、一个有效恢复码、新密码并明确确认。账号与码错误/过期返回相同信息；持久化来源尝试预算为每 15 分钟 60 次，与其他认证操作共享。重置锁定账号，在同一事务修改密码/凭证版本、撤销全部会话并使剩余恢复码失效。重新登录后再生成恢复码。短信重置、换号和账号合并推进相同凭证版本，旧版本恢复码也失效。

该方案无需邮件、短信费用，邮箱账号可用；必须在仍能登录时预先保存恢复码。没有恢复码、没有可用的已验证手机号时，不能仅凭知道邮箱自助恢复，也没有管理员万能重置入口。已有短信流程仍保留，但学习配置不发送真实短信。此阶段不宣称邮件所有权验证或真实短信送达已验收。

## AI 应用预扣额度

默认收费模式关闭。只有显式设置 `AI_ALLOWANCE_ENABLED=true` 且模型完整配置时才使用真实模型；否则文字规划/建议用演示模式，图片识别不可用。学习部署继续关闭收费模型，常规验收仅使用本地确定性 HTTP fixtures。

默认额度由服务端环境控制，客户端不能提高：

| 配置 | 默认 | 含义 |
| --- | --- | --- |
| `AI_MONTHLY_ALLOWANCE_CNY` | 5 | 每个家庭及整个服务共同的月度预扣上限，避免新建家庭绕过 |
| `AI_TEXT_CALL_ALLOWANCE_CNY` | 0.10 | 每次文字请求全额预扣 |
| `AI_IMAGE_CALL_ALLOWANCE_CNY` | 0.50 | 每次图片请求全额预扣 |
| `AI_DAILY_CALL_LIMIT` | 20 | 全服务每日最多收费请求 |
| `AI_CONCURRENT_CALL_LIMIT` | 1 | 全服务同时进行或待核查的请求上限 |

金额按千分之一元整数记录，最多三位小数，不用浮点。月/日窗口按北京时间；并发包含旧月份的待核查请求。请求发送前，在 PostgreSQL 事务中以全服务锁检查额度、每日次数、并发、当前家庭角色及任务租约，提交唯一任务预扣。文字 JSON 请求上限 32 KiB/输出上限 1600 tokens，图片仍有上传大小/输出 400 tokens 限制。发送 HTTP 前必须预扣成功；同一任务不能再次收费发送，Worker 重启、手动 retry 和过期租约都不重置此记录。HTTP 重定向不会转发第二次请求。

完整返回的请求释放并发，但保留全部预扣；请求报错、结果无效或取消不返还预扣。网络超时、进程崩溃、账务写入失败留下 `pending/uncertain`，额度和并发均保留，不自动重新付费。这样会保守地提前停止服务；每个菜单/建议仍需用户确认后才写业务数据，预算保护不会代替权限或确认。

**这是应用预扣硬上限，不是 DeepSeek 账单硬封顶，也不是实际 token 结算。** 模型/价格/图像计费/汇率可能改变，预扣值需要操作者根据所选服务的最坏请求费用核对；在没有核对前保持收费开关关闭。当前 [DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) 有高峰/空闲、输入缓存及模型差异，不能把每次 ¥0.10/¥0.50 当作所有模型的实际价格或保证。账单精确对账、动态调价和真实图片计费覆盖仍需后续验证。

## 手动核查可能收费的请求

个人主页“AI 调用额度”展示家庭与服务预扣、每日次数、进行中/待核查数量。以下维护工具仅访问固定学习数据库，默认只读脱敏汇总；不会读取或打印模型密钥。

```powershell
pwsh -File scripts/ai-allowance-review.ps1 -Action status
# 仅在操作者已经确认服务商请求结束并核对账单后，使用任务页的实际 UUID：
pwsh -File scripts/ai-allowance-review.ps1 -Action acknowledge -JobId 实际任务UUID -ConfirmProviderFinished
```

确认命令只允许超过五分钟且任务已 failed/cancelled、没有有效租约的记录；它释放并发，保留全部预扣，不发送重试，不退额度。五分钟只是防误操作的最低等待，不能替代核查服务商。仍运行/未确定请求结束时保持冻结。不要直接删除预扣表来重新获得额度。

确定性回归覆盖恢复码竞争/轮换/过期/凭证版本/会话撤销/限流，AI 额度并发竞争/重启/同任务重复/跨月不确定性/每日上限/请求大小/发送前拒绝和禁止重定向。实际证据与失败记录见 [学习交付计划](exec-plans/learning-release.md)，真实家庭体验仍在下一阶段。

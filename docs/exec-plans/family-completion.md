1. 同步已验证的契约、浏览器成功链、质量台账与真实食材照片；确认对应 GitHub CI。

4. 完善账号生命周期，使用确定性短信 fixture 验证权限、验证码、撤销会话与确认边界。
5. 补齐可确认的营养换算/分类与剩余 API 契约、生成前端类型。
6. 绑定验收镜像与源码，补家庭规模负载验证与可操作的试用指南；更新质量台账、启动环境与 GitHub。

# Harness maintenance constraints

The executable feedback loop must retain:

1. Generated selected source facts and local-link checks that reject drift; semantic documentation review remains necessary.
2. Architecture import boundaries and required Docker-backed integration tests.
3. Isolated browser/platform acceptance, source-bound image manifests and read-only redacted diagnostics.
4. Task starts and actual outcomes; completion rejects stale/incomplete full evidence and outcome overwrites.
5. Commit-specific cloud results. Wall-clock duration includes waiting and does not establish AI productivity or user benefit.

Regression checks cover bounded transient read recovery, permanent errors/timeouts, gateway replacement while its IP changes, synthetic authentication-budget preparation, generated contract consistency and stale/foreign image bindings. They preserve production authorization, limits and development data.

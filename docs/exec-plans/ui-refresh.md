# 食光整体界面完善

2026-10-01，用户要求增强整体 UI 与页面效果。范围为现有本地家庭试用网页：共享视觉、导航、登录、今日概览、食材选择和各页切换；保留库存、授权、采购与做饭的确认流程。task `ui-refresh-20261001`（feature，baseline unknown）。

## 实施

- 奶油白与鼠尾草绿背景、统一圆角与卡片层次、按钮和表单焦点反馈；桌面导航与手机安全区域适配。
- 今日标题与家庭名称分开显示，数字名称明确标注为“当前家庭：4”。状态来自已读取的库存、任务与采购数据，加载或失败显示破折号；不合并不同单位的数量。
- 首页与登录页使用项目已有授权食材参考照片作装饰，目录图片使用 4:3 比例；家庭上传照片与回退逻辑保留。
- 添加轻量页面进入与弹窗动效，尊重减少动态效果设置；页面切换保留按钮语义和当前页标记。
- 现有真实登录/导航浏览器场景覆盖数字家庭名称与页面分离、减少动态效果、各主页面窄屏不横向溢出，保存登录与主页面截图供人工检查。

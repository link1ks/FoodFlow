## 范围与边界

业务写入只发生在 `127.0.0.1:15173` 的独立验收部署和新虚构账号中。
默认 `localhost:5173` 只做无登录只读构建核验。模型输出使用确定性 fixture；
本任务不授权收费调用，不宣称真实图片识别、ASR、短信或物理设备验收。
历史稳定版的模型与设备阻塞不因这次 UI 任务而消失。

契约绑定前已查询本地工程经验，查询显式限制适用版本 `0.3.0`，空错误码
表示查询全部 UI 故障；未返回可采用的已验证相关记录。私有查询证据为
`.cache/harness/ux-real-showcase-retrieval.json`，不以无命中推断不存在问题。

## 操作覆盖与证据位置

主代理已通过 IAB 在运行中的15173界面逐步操作：创建新虚构账号，进入个人厨房；
观察旧版库存顶部按钮只滚动；在目录搜索生菜并入库100g；搜索蒜香生菜，选择
1人晚餐，确认后获得生菜50g和蒜10g采购缺口；逐项通过UI确认采购入库，在今天
页面确认烹饪完成；最后在库存流水中核对`-100g`、`-50g`、`-10g`三条扣减。
另在查菜价搜索生菜，页面明确显示暂无已核验数据，并把历史快照与当前价格区分。
IAB当时约304px宽，目视确认旧记录切换区占满首屏。

这是代理通过用户可见控件逐步进行的实际走查，未输出认证头或token，
也未访问默认数据库；它不等于物理手机验收，不替代后续全套桌面／手机自动化结果。
正式公开素材由专用录制脚本另行采集，不把这次未录制的点击补画成视频。

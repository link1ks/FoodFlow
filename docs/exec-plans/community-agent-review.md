# Community agent preliminary review

Date: 2026-10-12. Task: `community-agent-review`. Owner: kitchen API/Worker and web.

New submissions require explicit consent to text/cover review and remain private until approval. The worker reviews recipe text and normalized covers using a structured multimodal adapter; no model output can directly publish or award points. Rejected submissions can be edited and explicitly resubmitted. Unconfigured services, invalid outputs and failed calls stay non-public. Existing posts retain visibility as legacy content without claiming an AI review.

Use a durable per-post revision queue, leases and unique dispatch records. Network requests run outside community write transactions. Share the existing service allowance lock and totals; unknown network outcomes retain reservations and never trigger automatic paid resends. Approval, replay-safe publication points and visibility commit together. Only approved/legacy posts participate in interaction, ranks and library admission.

## Limits and configuration

Current development boolean checks confirm paid allowances are disabled and neither the dedicated review nor vision provider is configured. Real submissions therefore remain private with an unavailable status until the owner configures a vision-capable provider and explicitly enables allowance protection. No secrets were read or copied, and no paid model setting was enabled. Configuration and consent rules are in [community documentation](../COMMUNITY.md).

This is model preliminary review, not a guarantee of cooking safety or content-policy accuracy. Real model quality, adversarial accuracy, sustained moderation load, multi-account voting abuse and report/appeal handling remain unverified. Manual administrator review is still required for weekly library admission. Ambiguous dispatch records require explicit operator investigation; they are never silently refunded or automatically resent. Local tests used installed Edge rather than CI's bundled Chromium. Cloud CI and production deployment were not run for this uncommitted worktree.

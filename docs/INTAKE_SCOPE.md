# 食材录入范围与语义限制

2026-10-16。语音和图片只服务于本次新增食材，识别不修改库存，最终写入仍要求用户明确确认。范围限制是减少误识别的措施，不能保证所有无关输入都能被正确识别。

## 语音

正式流程为 Qwen ASR → 本地 `intake.Interpret` → 可编辑草稿 → 显式、幂等、整批事务确认。本次没有把实验文本模型接入生产，也没有增加第二次收费模型调用。ASR 原文本始终保留供核对。

本地解释器先拦截提醒、问答、查询、历史记录、引用、包装文字和系统指令，再逐句检查食材目录名称、精确数量与有限语法。每句必须被完整解释，不能从“苹果手机一个”“添加鸡蛋三个，电脑一台”里截取食材数字入库。结果为 `draft`、`clarify` 或 `noop`：

- 明确的新增与单位换算生成草稿。数量仍由原有定点数量函数换算，不用浮点数猜测。
- 同种食材的明确改口采用最终数量；多食材必须明确说出修改目标。单一目标可以省略食材名称。“鸡蛋三个，改成四个”为四个；“番茄500克，鸡蛋三个，把它改成四个”要求澄清。
- 明确否定不生成该项；撤回只移除本次尚未确认的草稿，不能删除已有库存。比如“番茄500克，鸡蛋两个，取消番茄”只保留鸡蛋两个。
- 估计、包装换算、重复批次、指代不清、冲突否定/改口要求重新表述或人工填写。包装容量和重量不猜。
- 无关或未消费的内容整段拒绝，`noop` 返回空条目。页面不显示添加/确认控件；服务端也拒绝伪造的确认请求。可重新录音或使用食材目录。

语法刻意有界，未列入语法的合理口语也可能被拒绝；用户应改说“添加食材名称＋数量＋单位”。方言、噪声、物理麦克风和真实用户分布仍未验收。

## 图片

一次视觉调用报告 `{scene, foods}`：先判断照片、文字、插画、截图、混合菜品或不确定，再盘点所有可见的真实食材。模型不再直接决定是否允许入库。服务端同时要求：

1. `scene` 为真实照片，`foods` 恰好一种；文字、仿真食物、杂物、混合菜品、多种食材、空结果及无效/截断 JSON 均拒绝。
2. 名称必须唯一匹配当前食材目录或别名，分类由目录填写。目录外名称不能成为图片草稿；确认 API 再检查一次目录，改名为非食材也无法提交。
3. 用户在确认页从目录选择食材，填写实际数量、单位和可选日期。无关图片不会生成确认页。拒绝/失败时尝试删除暂存图片，原任务不能重新派发；重新拍摄并提交是一个新任务。

这是模型观察结果上的严格程序校验。若模型把实物电脑错误描述为番茄，目录校验本身无法证明图中有番茄；仍需人工核对和更多独立样本，不能宣称任意无关图片都绝不会误通过。单种食材照片中的普通桌面、餐具可作为背景，但其他可见食材会使本入口拒绝。

## 响应速度

范围判定与识别合并为一次视觉请求，关闭思考、最多输出 120 token，图像请求设置 `max_pixels=1048576`，单次模型调用 deadline 为 12 秒，无自动重试。参数依据 [百炼图像理解接口](https://docs.modelstudio.console.alibabacloud.com/zh/model-studio/vision)。文件格式/大小检查和语音文本范围判断在本地进行；图片内容判断需要模型。12 秒不包括上传、Worker 排队、数据库和清理时间，不是整页响应承诺。

最终版 15 张已返回样本的模型调用为 0.721–9.023 秒，详细延迟在脱敏证据中。不能把这次小样本的延迟当作稳定的服务等级。默认站点配置和收费开关没有改变，代码发布不代表默认站点已重建部署。

## 验证与边界

旧的 100 条合成文本：旧规则 45/100 完全符合、七条错误草稿；新解释器 91/100 完全符合、零条错误草稿、九条保守拒绝。九条被拒绝仍计作错误，没有把拒绝率冒充准确率。新增 60 条在首次执行前冻结的合成文本：旧规则 20/60、十五条错误草稿；新解释器 60/60、零条错误草稿。这些都是实现者编写的标签，没有独立标注复核，不是代表性用户准确率。

真实图像分三版进行，保留每一版结果。第一版“允许/拒绝＋名称”的提示词在 15 个返回样本中仅 11 个符合原标签，错误放行两张文字/指令图片和两张混合食材图。第二版改为图像载体和全量食材观察后，八张非食材/混合样本均拒绝，但对香蕉品种过度拆分。最终版去掉给模型的目录清单，避免目录诱导，并统一同种食材不同颜色/成熟度：原冻结标签 14/15，六张单种食材通过，八张非食材/混合样本均拒绝。

另一张原标“黄瓜”的仓库照片，经查看原图发现背景有胡萝卜和菠萝，原来的“单种”标签不合适。保留原标签和 14/15 分数，不追改成满分；模型在这张图还输出了大量不存在的食材并截断，程序拒绝。这不计作模型理解成功，也说明现有目录图片不能直接作为干净单食材评测集。

主机最初发送的番茄图 12 秒超时，记录为不确定，三个后续容器批次均排除此摘要，没有盲目重发。每版其余 15 张各发送一次，45 个 HTTP 200 返回，另一个主机请求结果不确定；共观察到 37,798 token，实际账单和免费额度覆盖未对账。发送前本地额度预留、私有新日志、无重定向/自动重试保护用于测试，不修改应用收费开关或业务库存。三次是明确版本复测，不声称为独立盲测。

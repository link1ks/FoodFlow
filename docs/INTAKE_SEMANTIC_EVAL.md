# 一百次语义理解试验

2026-10-15，用户授权先试 100 次。范围为文本转写后的语义解析，不重复调用 ASR、OSS 或库存 API；预算上限 2 元。使用北京百炼 `qwen-plus-2025-12-01`，非思考模式、temperature=0、最多 600 输出 token，每条只发送一次，共 100 次 HTTP 200，无重试。没有接入正式录入或部署网页。

## 冻结样本与评分

[100 条构造样本](../tests/fixtures/intake-semantic-100.json) 分十类，每类十条，给出预设答案；不是代表性真实用户样本，也没有独立人工标注复核。模型只看目录和输入文本，看不到答案。提示词及样本在发送前冻结，保留摘要：

- 样本 SHA256：`86a7bce09b711c0eb5d2e9fe96e8dd69f9c29e96e5bd6f98c59d16837cb4339b`
- 提示词 SHA256：`29f17dd09c7516f1f039cfc0c464554ad71db645adfa72bf84f725a1bf453ddd`

`draft` 要求食材集合及精确数量完全一致；`clarify` 是需要用户澄清；`noop` 是本次无需新增。不确定的多食材代词、估计数量、未知包装等按预设保守标准要求澄清。比如“番茄500克、鸡蛋三个，把它改成四个”按此标准算指代不明确，即便某个解释看似合理也不能直接给草稿。分数依赖这套标准，不是通用自然语言准确率。

模型只能返回目录 ID 和原文中的数量单位片段，不能自己生成数量、库存操作或日期。纯函数校验未知字段、目录白名单、逐字来源、重复食材和单位换算；数量使用现有定点解析。**数字能在原文找到，不代表新增意图、否定范围或指代正确。** 返回仍只是待人工确认的实验提案。

模型在明确改口上更有用，却把“别加鸡蛋三个”当成新增，把“鸡蛋两个，不要番茄500克”中的番茄也加入，对“大概/差不多”给出确数，还把明天购物提醒当成本次入库。三个否定、三个违反预设歧义标准、一个未来提醒，共七条错误草稿。半斤、一点五千克等本可换算的表达有时又退回澄清。四条不合格提案包括缺单位、苹果个数与克不兼容、一打鸡蛋、洋葱一根。

**本轮不建议把该模型提示词直接替换正式解析器。** 完全符合多了三十条，但错误草稿总数没有减少，且否定/歧义子类变差。既有规则保护和显式确认保持不变。该结论只针对本版本、提示词和构造样本；没有进行同批付费重调或测试其他模型，不能推断所有模型均如此。

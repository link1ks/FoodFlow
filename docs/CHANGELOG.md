## v0.2.0 — 2026-10-01

### 家庭厨房交互

- 主导航收敛为今天、食材、菜单、采购、记录；手机使用底部导航。
- 首页优先展示近期任务、已过期与临期食材、今日菜单和采购待办。新手指南可收起，日常用户可从帮助重新打开。
- 菜单、识别与搭配建议回到对应操作页面，离开后可继续处理；营养、食材用量、库存流水和生成记录分开展示。
- 食材目录支持连续添加、数量快捷选择与本次添加清单；日期、位置和补货线收进选填区，再买一批时清空旧数量和日期。
- 生成前提示演示模式；统计未启用时不发送统计查询，临时故障保留重试。
- 烹饪扣库增加确认弹窗，取消不提交完成请求。

### 接口与版本

- 新增家庭鉴权下的最近 100 条库存流水查询。名称、单位采用不可变历史快照，缺失事实明确保留未知。
- 扩展功能配置查询，说明模型与统计是否配置；配置状态不等于服务实时健康。
- 前端包、OpenAPI 与本次 Git 标签采用 v0.2.0；个人中心显示前端版本。

### 验证与边界

交互改版当时已通过本地完整 Harness、平台恢复、厨房主流程及六个桌面／手机 Chromium 场景。当前版本的检查入口与验证边界见 [验证说明](VERIFICATION.md)。本地验证不证明公网部署、真实模型质量或家庭操作耗时改善。
